# OpenBumpPlan 0.4.0 engineering notes

## Generated routes, not merely supplied witnesses

The generator and independent grid verifier accept at most 4,096 assignments (formerly 512). `routeStage` and `routePhysical` can generate them; the 4,096-route regression checks grid occupancy, continuous copper clearance, content-bound review replay, and unchanged input state. The old v0.3.1 4,096-route copper fixture only checked supplied geometry. These are different claims.

The favorable scale fixture is a 512 by 512 single-layer grid with separated six-step connections, eight coordinate units per local cell. It needs explicit zero origins and 512 columns/rows; automatically added margins would exceed the existing grid bound. This is not a congested package qualification, electrical model, escape-routing guarantee, or vendor comparison.

## Search storage

`SearchWorkspace` holds one distance array, one predecessor array and two generation arrays: 20 bytes per grid node, or 5,242,880 bytes at 262,144 nodes. Only visited nodes are initialized in each search. A generation wrap clears both tag arrays before reuse. All direct A* searches in one routing context reuse this workspace. Negotiated routing has its own context after the initial attempt and reports separate statistics. The 5 MiB figure is **search-array storage**, not total process memory, peak heap, or combined storage of multiple contexts.

The frozen previous router is retained only under tests. Eighty fixed randomized tests compare the actual paths, failures and diagnostics, not only route counts. Epoch wrap, invalid lengths, exhausted work, and the assignment cap are separately tested. Grid size (262,144 cells including layers), total search expansions (2,000,000), and independent witness work (1,000,000 nodes) retain their prior ceilings. All are operational limits, not a guarantee of bounded wall-clock latency or industrial completeness.

## Correct contact rejection

Previously, the positive-clearance branch subtracted the numerical tolerance from the entire required center distance. A positive clearance below that tolerance could therefore authorize physical contact. The new predicate separately rejects contact within tolerance, for every nonnegative clearance, and then checks the requested positive gap. This is an intentional stricter correctness change. Regression cases include touching and slightly overlapping traces, trace/pad and pad/pad contact, keepout contact, tiny clearances, and a genuine gap that must still pass.

## UI freshness

Engineering results carry a stable serialization of the control values used to compute them. A later change in geometry, technology or routing controls marks the result stale and disables apply/review-export operations. Asynchronous bundle generation rechecks settings and project state after awaiting computation. Explicit bounds can be blank (automatic); negative grid origins are supported. No worker result or project mapping is fabricated in the browser scale test.

## Bounded source import

The overlay helper bounds encoded input before decoding, compressed bytes before decompression, decoder memory before expansion, and output to at most the 10,000,000-byte budget plus one rejection byte. It rejects truncated, corrupt, trailing and concatenated XZ streams. Before writing, every tar member and destination is validated against the manifest, regular-file requirements, size limits, canonical paths, protected directories, symlinks and file/directory collisions. The checksum is integrity evidence, not authentication or permission to run untrusted workflows.

## Evidence and comparison boundaries

Review examples are newly computed by engine 0.4.0, not historical approvals with their version text edited. Older signed bundles need their original verifier or a newly authorized review. Benchmarks compare with frozen OpenBumpPlan implementations, never a closed-source EDA executable. Work-limited results remain incomplete, not verified or a proof of infeasibility. SI/PI, thermal, mechanical, foundry/PDK signoff, and industrial round-trip interchange remain unqualified.
